# Zardui Component Usage Guide — ⚠️ Deprecated

**Do not use this file.** It predates `ZARDUI_AI_REFERENCE.md` and was never reconciled with it. An August 2026 documentation audit found nearly every example in the old version of this file used a fictional or superseded Zardui API — wrong button/badge variant names, a card sub-component structure that doesn't exist, a fictional `z-multi-select`, wrong pagination inputs, a `ZardDialogRef`/`ZardSheetRef` `.closed` property that was never real, and more.

Its content has been removed rather than repaired, since `ZARDUI_AI_REFERENCE.md` already covers the same ground correctly and this file's continued existence only contradicted it.

**Use [ZARDUI_AI_REFERENCE.md](./ZARDUI_AI_REFERENCE.md) instead** for every Zardui component question — selectors, inputs, variants, and usage examples. See also `zard-quick-ref.md` (`libs/ui/src/lib/zard/`) for a fast selector/import lookup, and `components.context.md` for the underlying component inventory.
